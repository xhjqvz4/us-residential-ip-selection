## 住宅IP、原生IP、双ISP、家宽VDS，四个词各指什么

**住宅IP**说的是IP的归属方：这个IP登记在家庭宽带运营商名下，AT&T、Comcast、Frontier、Astound Broadband这类，不在数据中心名下。TikTok、Instagram、亚马逊、ChatGPT这些平台会读这个字段，看到机房段就降权、限流，严重的直接封号。买住宅IP买的就是这一条。

**原生IP**说的是IP注册地和服务器实际所在地一致。洛杉矶的机器配一个注册在洛杉矶的IP，叫原生；配一个注册在德国的IP，叫广播。原生IP解决的是“这个IP看起来属于哪”，不解决“它看起来是不是机房”。

**双ISP**是IP同时带两个ISP属性标记，检测工具里Company字段和ASN字段都指向ISP。这个标记比单ISP更难伪造，第三方测评普遍把它当作可信度更高的一档。

**家宽VDS**是硬件层面的差别：宿主机直接放在美国真实民房里，接当地家庭宽带的光纤，不是机房里切出来的一段“住宅属性IP”。IP质量最高的一档，代价是带宽和流量都按真实家宽的上限来，超了就是真超了。

这四个词经常被混着卖。一个套餐写着“美国原生IP”，可能只是机房IP注册在美国；写着“住宅IP”，可能只是广播段伪装。所以买之前要能自己验。

## 双ISP怎么自己验，三步够用

第一步看ipinfo.io。Company那一行的type如果是ISP，是一个信号；再看ASN的type，也显示ISP，两个维度互相印证才算通过。只满足一个的，有可能是广播段做出来的。

第二步看scamalytics的风险分。分数越低越好，这个工具会综合IP的历史行为、代理记录、黑名单情况打分。同一家商家不同批次的IP，分数可能差很多，所以到手再验一次。

第三步是实测业务环境。把要跑的账号或工具挂上去，看平台自己的IP检测结果，TikTok有专门的检测入口。工具判住宅、平台判机房的情况不少见，两边都过才算数。

## 退款条款里的四种分层

这类产品的退款政策不是“七天无理由”一刀切，公开条款里能看到至少四种处理方式，买之前必须逐条读完。

**48小时无条件退款**：多数标准VPS产品线适用。听起来宽松，但条款里通常带门槛，比如带宽使用量超过套餐的5%或20GB（以较小值为准）就不退，安装费、支付处理费不退，被判定滥用的不退。

**48小时后个案处理**：超过窗口期要谈，且通常要求放弃该时段之后的退款权利。

**仅退网站余额**：家宽VDS这类特殊产品常见。钱不退支付宝，退成站内余额，等于强制复购。

**完全不退**：CN2 GIA共享NAT这类稀缺资源，条款里直接写“特殊产品，无退款”。

另外两个容易漏的点：家宽VDS按IP提供方要求可能禁ping，ping不通是正常现象，用ping判断线路质量会误判；CN2 NAT共享是手动开通，24小时内交付，不是即时开通，着急用的人要算进去。

下单前把这三件事在订购页上确认一遍：退款类型、是否即时交付、流量超了怎么算。

## FAQ

**双ISP自己能验吗？**
能。ipinfo看Company和ASN两个维度是否都显示ISP，再用scamalytics看风险分，最后在目标平台实测一遍。三步都过再放心用。

**9929和4837怎么选？**
看你的宽带。电信为主选9929，延迟低且稳；联通、移动为主选4837，同价位带宽和流量给得多。

**ping不通是不是机器坏了？**
不一定。部分住宅IP段按提供方要求禁了ping，这是正常现象，用业务实测或traceroute判断更准。

**年付一定比月付划算吗？**
按总价算一定便宜，按单位流量算不一定。特价年付档的流量往往只有600GB/月，先估自己的月消耗再决定。

**装Windows麻烦吗？**
部分商家要开工单人工装，且建议2GB内存起步，1G内存的套餐装起来会卡。着急用Windows环境的，下单前先问清楚。
